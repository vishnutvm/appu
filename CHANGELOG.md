# Changelog

All notable changes to this project are documented here. Release binaries and checksums live on [GitHub Releases](https://github.com/vishnutvm/appu/releases).

## [Unreleased]

### Added
- Open-source governance: MIT license, CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, AGENTS
- GitHub CI workflow (test + build on push/PR), issue/PR templates, Dependabot
- Architecture and AI privacy docs; README screenshots from official website
- Desktop-only product surface (`DesktopOnlyGate`; browser studio UI removed)

## [1.0.4] - 2026-11-12

### Added
- Rabbit Batch A/B: thinking, happy, surprised; falling, landing, recovering physics
- Companion scale control persisted in settings

### Changed
- Release CI builds macOS arm64 + x64 and Windows NSIS in sequence

## [1.0.3] - 2026-11

### Added
- Rabbit video companion, character picker, and in-app updater fixes
